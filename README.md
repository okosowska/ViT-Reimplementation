# ViT-Reimplementation
This is a simplified re-implementation of the paper “An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale” by  Dosovitskiy et al., which introduced the concept of Vision Transformers. It has been trained and tested on a small dataset - CIFAR-10 (60,000 images). The model achieves 64.07% accuracy over 7 epochs of training.
